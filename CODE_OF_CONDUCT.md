# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, criticize ideas rather than people,
and accept that maintainers may remove comments, commits or contributors that
do not follow it.

To report unacceptable behavior, use GitHub's
[private reporting](https://github.com/dvalfrid/git-branchline/security/advisories/new)
or contact the maintainer through their GitHub profile. Reports are kept
confidential.
